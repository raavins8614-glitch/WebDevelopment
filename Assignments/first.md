# Assignment 1: My First HTML Web Page

## Objective
Create a simple HTML webpage using only the following HTML tags:
- `<h1>` to `<h6>`
- `<p>`
- `<pre>`
- `<a>`
- `<br>`
---
# Instructions

Create a file named **index.html** and build the webpage by following the steps below.

---

## Step 1: Create the Main Heading

Use the `<h1>` tag.

**Heading:**

Welcome to My First Web Page

---

## Step 2: Introduce Yourself

Use a `<p>` tag and write the following paragraph.

**Paragraph:**

Hello! My name is ____________. I have recently started learning Web Development. This is my first HTML assignment where I am learning how websites are created using HTML. I am excited to begin this journey and build many interesting projects in the future.

---

## Step 3: About Me

Use the `<h2>` tag.

**Heading:**

About Me

Use a `<p>` tag.

**Paragraph:**

I enjoy learning new technologies and solving problems using programming. My goal is to become a skilled Web Developer who can build fast, responsive, and user-friendly websites.

---

## Step 4: Why I Chose Web Development

Use the `<h3>` tag.

**Heading:**

Why I Chose Web Development

Use a `<p>` tag.

**Paragraph:**

Web development allows me to create websites that people can use every day. I enjoy designing webpages and learning how different technologies work together to create amazing user experiences.

---

## Step 5: Skills I Want to Learn

Use the `<h4>` tag.

**Heading:**

Skills I Want to Learn

Use a `<p>` tag.

**Paragraph:**

I want to learn HTML, CSS, JavaScript, React, Node.js, databases, and backend development. Every new topic will help me become a better developer.

---

## Step 6: My Dream Career

Use the `<h5>` tag.

**Heading:**

My Dream Career

Use a `<p>` tag.

**Paragraph:**

My dream is to work as a Software Engineer where I can build useful applications, solve real-world problems, and continuously learn new technologies.

---

## Step 7: Thank You Message

Use the `<h6>` tag.

**Heading:**

Thank You for Visiting

Use a `<p>` tag.

**Paragraph:**

Thank you for visiting my very first HTML webpage. This assignment is the beginning of my journey into the exciting world of Web Development.

---

## Step 8: Use the `<br>` Tag

Create the following information using **one paragraph** and the `<br>` tag so that every item appears on a new line.

```
Name: __________

Age: __________

City: __________

Country: __________

Favorite Programming Language: __________

Favorite Hobby: __________
```

---

## Step 9: Use the `<pre>` Tag

Display the following exactly as shown.

```
           My Learning Roadmap

                 HTML
                   |
                 CSS
                   |
              JavaScript
                   |
                React.js
                   |
            Full Stack Developer
```

---

## Step 10: Add Useful Links

Create a heading.

**Heading:**

Useful Learning Websites

Below the heading, create clickable links for the following websites.

Google

https://www.google.com

MDN Web Docs

https://developer.mozilla.org

freeCodeCamp

https://www.freecodecamp.org

W3Schools

https://www.w3schools.com

---

## Step 11: Final Paragraph

Use a `<p>` tag.

**Paragraph:**

This webpage was created as my first HTML assignment. I have learned how to use headings, paragraphs, line breaks, preformatted text, and hyperlinks. I look forward to learning CSS and JavaScript next.

---

# Expected Output

Your webpage should contain:

Welcome to My First Web Page

About Me

Skills I Want to Learn

My Dream Career

Personal Information

My Learning Roadmap

Useful Learning Websites

Final Paragraph
